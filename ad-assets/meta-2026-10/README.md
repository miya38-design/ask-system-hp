**AI動画生成は使っていません。** 人物の手や顔、日本語テキストが生成時に崩れるためです。

BGMを付けたい場合は Meta の音源ライブラリから広告マネージャ上で追加できます
（権利処理済みの音源が使えます）。

## 配信設定の目安

- **地域**：水俣市を中心に半径30〜40km、または 八代市・水俣市・芦北町・津奈木町・出水市 を個別指定
- **年齢**：ad1 は 45歳以上／ad2・ad4 は 30歳以上／ad3 は 35歳以上
- **配置**：自動配置（Advantage+）でまず回し、効いた面に寄せる
- まず **ad1 と ad2 の2本**を同時に回して比べるのがおすすめです。
  1本ずつ出すより、どちらが刺さるか早く分かります

## 表記について（重要）

価格を出す広告なので、**「※別途、出張費・部材費がかかる場合があります」を画像内に入れています。**
これを消さないでください。6,600円〜とだけ表示して追加費用に触れないと、
景品表示法の有利誤認にあたるおそれがあります。

使っている数字はすべてサイトの掲載と一致しています。

- 設定・トラブル対応 6,600円〜（税込）… 料金表の最低価格
- 地域密着20年以上 … トップページの記載
- 最短即日 … 特商法ページの「役務の提供時期」
- ご相談・お見積り無料 … 会社概要の記載

**営業時間は画像に入れていません。** 制作時点では Googleマップの掲載と
サイトの記載が食い違っていたためです。**2026年10月7日に「9:00〜18:00（年中無休）」が
正しいと確認が取れました。** 画像に入れたい場合は、スクラッチの `build.py` で
各クリエイティブに追加して再出力できます（依頼いただければ対応します）。

なお、Googleマップ側の掲載（終了17:00）は未修正です。ビジネスプロフィールの
営業時間を 9:00〜18:00 に直してから広告を出すと、表示が揃います。

## 作り方

イラストは AI生成（文字なし）、日本語コピーは HTML/CSS で重ねてレンダリングしています。
画像生成AIに日本語を書かせると崩れるためです。

修正したい場合は、スクラッチの `build.py` でコピーと寸法を変えて再出力できます。
文言の差し替えだけなら、そのまま依頼してください。
