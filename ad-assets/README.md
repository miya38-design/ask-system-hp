## 使い方メモ

- **SNSアイコン**：実際のASKロゴを参照生成しているためブランド一貫性あり。
  各SNSは円形に自動トリミングされるが、余白を取ってあるので切れない。
- **動画**：文字は焼き込んでいない（動画AIは日本語が崩れるため）。
  Meta広告では見出し・説明文は広告枠側に入力するのが標準。BGMは生成音声入り。
- **ストーリーズ**：上下15%は各プラットフォームのUIを避けて余白を確保済み。
- 静止画は2K。Meta入稿時は自動圧縮されるためそのまま入稿可。
