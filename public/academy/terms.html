利用規約

この規約は、ASKデジタルアカデミーをご利用いただくうえでのお約束をまとめたものです。 お子さまが安心して学べる場を保つため、ご入会前に保護者の方が必ずお読みください。

制定日：2026年9月10日 最終更新：2026年9月10日 対象：小学3〜6年生

本規約は、アスクシステム（以下「当校」といいます）が運営する学習教室「ASKデジタルアカデミー」（以下「本教室」といいます）のご利用条件を定めるものです。 入会をお申し込みいただいた時点で、保護者の方および会員本人に本規約へご同意いただいたものとみなします。

第1条目的・適用

  1. 本規約は、本教室が提供するサービスの利用に関し、当校と保護者および会員との間に適用されます。
  2. 当校がウェブサイト、公式LINE、マイページ等で掲示する個別のご案内は、本規約の一部を構成します。
  3. 個別のご案内の内容が本規約と異なる場合は、個別のご案内が優先して適用されます。

第2条定義

  1. 「本教室」とは、当校が運営する学習教室「ASKデジタルアカデミー」をいいます。
  2. 「会員」とは、本規約に同意し、当校の承認を得て入会したお子さまをいいます。
  3. 「保護者」とは、会員の親権者または法定代理人をいいます。
  4. 「本サービス」とは、本教室が提供する学習環境、教材、設備、およびマイページ等の会員向けオンライン機能の総称をいいます。

第3条対象・入会資格

  1. 本教室の対象は、小学3年生から小学6年生までのお子さまです。
  2. 入会には保護者の同意が必要です。
  3. 次のいずれかに該当する場合、当校は入会をお断りすることがあります。
    1. お申し込み内容に事実と異なる記載があった場合
    2. 過去に本規約違反により退会処分を受けたことがある場合
    3. その他、本サービスの運営に支障があると当校が合理的に判断した場合

第4条入会手続き

  1. 入会のお申し込みは、当校の公式LINEアカウントから行っていただきます。
  2. 当校がお申し込み内容と初回受講料のお支払いを確認した時点で入会が成立し、会員機能をご利用いただけるようになります。
  3. 入会後、保護者用と会員用のログイン情報を発行します。ログインIDは共通、パスワードはそれぞれ別のものをお渡しします。

第5条契約期間・自動更新

  1. 契約期間は、入会日の属する月の末日までとします。
  2. 休会または退会のお申し出がない限り、契約は1か月単位で自動的に更新されます。長期の契約期間を設定するものではありません。
  3. 会員資格は、小学校をご卒業される年度の3月末日をもって終了します。継続をご希望の場合は別途ご相談ください。

第6条コースと受講料

コースおよび月額受講料は次のとおりです。

コース通学曜日月額受講料
週2回コース火・木6,000円
週3回コース月・水・金9,000円
通い放題コース月〜金12,000円
  1. 開校時間は16:00〜19:00です。
  2. 教材費、イベント参加費等が別途必要となる場合は、事前にご案内します。事前のご案内なく費用を申し受けることはありません。
  3. 受講料および諸費用を変更する場合は、変更の少なくとも1か月前までに、公式LINE、マイページまたは本ウェブサイトにてお知らせします。

第7条受講料のお支払い

  1. 受講料は月額制です。原則として、ご来校時に教室でお支払いいただきます。
  2. 月の途中でご入会いただいた場合の初月の受講料は、お申し込み時に個別にご案内します。
  3. お支払いいただいた受講料は、本規約に定める場合および法令に基づく場合を除き、返金いたしません。

第8条コースの変更

  1. コースの変更をご希望の場合は、変更を希望される月の前月末日までに、公式LINEまたは教室窓口へお申し出ください。
  2. 変更は、お申し出のあった翌月分から適用されます。
  3. 月の途中でのコース変更および受講料の差額精算は、原則として行いません。
ご家庭のご予定や学年の変化に合わせて、在籍中のコース変更は何度でも承ります。まずはお気軽にご相談ください。

第9条休会

  1. 休会をご希望の場合は、休会を開始される月の前月末日までにお申し出ください。
  2. 休会期間中の受講料はいただきません。
  3. 休会期間は連続して最大6か月とします。6か月を経過した場合は自動的に復会となり、受講料が発生します。復会の前に、当校から保護者へご連絡します。

第10条退会

  1. 退会をご希望の場合は、退会を希望される月の前月末日までにお申し出ください。
  2. 当月に入ってからお申し出いただいた場合、当月分の受講料は返金いたしかねます。翌月以降の受講料は発生しません。
  3. 退会後は、マイページ等の会員機能をご利用いただけなくなります。

第11条開校日・休校

  1. 開校曜日はコースにより異なります。祝日、年末年始、夏季休業のほか、当校が定める休校日があります。
  2. あらかじめ定められた休校日は、公式LINEおよびマイページでご案内します。
  3. 気象警報の発表、災害、感染症の流行、設備の不具合その他やむを得ない事情により、臨時に休校し、または開校時間を変更することがあります。この場合、可能な限り速やかにご連絡します。
  4. 臨時休校について受講料の返金は原則として行いませんが、休校が長期にわたる場合は、当校が定める方法により受講料の減額または期間の延長等の調整を行います。

第12条欠席・振替

  1. 欠席される場合は、事前に公式LINEまたはマイページからご連絡ください。
  2. ご都合による欠席について、受講料の返金または翌月への繰越は行いません。
  3. 振替の可否および方法は、ご在籍のコースおよび教室の受入状況により異なります。詳しくは教室にご相談ください。

第13条学習方法と生成AIの利用

  1. 本教室は、講師による一斉指導ではなく、教材とICT環境を活用した自学習を中心とする学習の場を提供します。
  2. 本教室では、学習支援を目的として、生成AIを含むICTツールを利用します。会員は、当校が定める利用ルールに従ってこれらを利用するものとします。
  3. 会員は、氏名、住所、電話番号、学校名、顔写真など、本人または第三者を特定できる情報を生成AIに入力してはなりません。当校は、この点について会員へ継続的に指導します。
  4. 生成AIの回答には誤りが含まれる可能性があります。当校は、生成AIの出力内容の正確性および完全性を保証しません。
  5. 当校は、学習の環境と機会を提供するものであり、会員の学力の向上、学校の成績、進学試験の結果等を保証するものではありません。
生成AIは「答えを写す道具」ではなく「自分で考えるための道具」として使うことを、本教室の基本方針としています。ご家庭でもご理解とご協力をお願いします。

第14条会員機能・アカウント管理

  1. 会員および保護者は、マイページ等の会員機能をご利用いただけます。
  2. ログイン情報は、保護者の責任において適切に管理してください。第三者への貸与、譲渡または共有はできません。
  3. ログイン情報の管理が不十分であったこと、または第三者に使用されたこと等により生じた損害について、当校の責めに帰すべき事由がある場合を除き、当校は責任を負いません。
  4. 当校は、システムの保守、障害対応その他必要がある場合、事前の通知なく会員機能の全部または一部を一時的に停止することがあります。

第15条入退室の記録と通知

  1. 本教室では、QRコード等による入退室の記録を行い、保護者へ通知する機能を提供する場合があります。
  2. この通知は、通信環境、端末の状態または外部サービス（LINE等）の状況により、遅延し、または届かないことがあります。
  3. 通知のみをもってお子さまの所在の確認とせず、必要に応じて教室へお問い合わせください。当校は、通知の遅延または不達のみを理由として責任を負うものではありません。

第16条安全管理・送迎

  1. 当校が安全に配慮する責任の範囲は、開校時間中の教室内に限られます。
  2. 教室までの往復（送迎を含みます）の安全については、保護者の責任において管理してください。
  3. 会員に体調不良、けが等が生じた場合、当校は応急的な対応を行うとともに、速やかに保護者へご連絡します。緊急を要する場合には、保護者へのご連絡に先立ち救急要請を行うことがあります。
  4. 保護者は、緊急連絡先を常に最新の状態に保つものとします。
  5. 教室内での私物の紛失または破損について、当校の責めに帰すべき事由がある場合を除き、当校は責任を負いません。高価な物品のお持ち込みはご遠慮ください。

第17条写真・動画の利用

  1. 当校は、教室の様子やイベントの記録として、会員の写真または動画を撮影することがあります。
  2. 撮影した写真または動画を、当校のウェブサイト、SNSおよび広報物に利用する場合があります。
  3. 前項の利用を希望されない場合は、いつでも公式LINEまたは教室窓口へお申し出ください。お申し出以降、速やかに対応します。すでに配布または掲載済みのものについては、可能な範囲で対応します。

第18条禁止事項

会員および保護者は、次の行為を行ってはなりません。

  1. 他の会員、当校のスタッフその他の第三者に対する暴力、暴言、いじめまたは差別的な言動
  2. 教室の設備、備品または教材を故意に破損し、または無断で持ち出す行為
  3. 他の会員の学習を妨げる行為
  4. 当校の許可なく教室内で撮影もしくは録音し、またはこれを公開する行為
  5. 生成AIその他のICTツールを、当校の定めるルールに反して利用する行為
  6. 会員機能への不正アクセス、または他人のログイン情報を使用する行為
  7. 当校の教材またはカリキュラムを無断で複製、転載し、または第三者に提供する行為
  8. 法令または公序良俗に反する行為
  9. その他、当校が不適切と合理的に判断する行為

第19条利用停止・退会処分

  1. 次のいずれかに該当する場合、当校は、本サービスの利用の停止または退会の処分を行うことがあります。処分にあたっては、緊急やむを得ない場合を除き、あらかじめ保護者へご説明します。
    1. 前条の禁止事項に違反した場合
    2. お申し込み内容に事実と異なる記載があった場合
    3. 受講料のお支払いが2か月以上遅延した場合
    4. 本規約に違反し、改善の見込みがないと当校が判断した場合
  2. 前項による処分の場合も、すでにお支払いいただいた受講料は返金いたしかねます。

第20条免責事項

  1. 当校は、相当の注意をもって本サービスを運営しますが、次の事由により生じた損害について、当校の故意または過失による場合を除き、責任を負いません。
    1. 天災、感染症の流行、停電、通信回線の障害その他の不可抗力
    2. 会員または保護者が使用する端末または通信環境に起因する不具合
    3. 外部サービス（LINE、生成AIサービス等）の仕様変更、提供停止または障害
  2. 当校が損害賠償責任を負う場合、その範囲は当校の責めに帰すべき事由により現実に生じた通常の損害に限られ、その額は、損害の原因となった事由が生じた月の受講料相当額を上限とします。
  3. 前項の定めは、当校の故意または重大な過失による場合、会員の生命または身体に生じた損害の場合、および消費者契約法その他の法令により無効とされる場合には適用しません。

第21条個人情報の取扱い

  1. 当校は、入会のお申し込みその他により取得した個人情報を、次の目的の範囲で利用します。
    1. 本サービスの提供、会員管理、出席および入退室の管理
    2. 保護者への連絡、通知および受講料等のご請求
    3. 本教室の運営に関する各種ご案内
    4. 個人を特定できない形での統計処理およびサービスの改善
  2. 当校は、法令に基づく場合を除き、あらかじめご本人の同意を得ることなく個人情報を第三者に提供しません。
  3. 当校は、業務の一部を外部に委託する場合、委託先に対して適切な監督を行います。
  4. 個人情報の開示、訂正、利用停止、削除等をご希望の場合は、本規約末尾の窓口へご連絡ください。法令に従い速やかに対応します。
  5. 退会後の個人情報は、法令に定める保存期間を経過した後、当校の定める方法により適切に廃棄します。

第22条反社会的勢力の排除

保護者および会員は、暴力団、暴力団員その他これらに準ずる者（以下「反社会的勢力」といいます）に該当せず、かつ将来にわたっても該当しないことを表明し、保証します。これに反することが判明した場合、当校は、何らの催告を要することなく、直ちに契約を解除することができます。

第23条法令に基づく解約

  1. 本契約が特定商取引法に定める「特定継続的役務提供」（学習塾については、契約期間が2か月を超え、かつ契約金額が5万円を超えるもの）に該当する場合、保護者は、法定の書面を受領した日を1日目として8日間以内であれば、書面または電磁的記録により契約を解除（クーリング・オフ）することができます。この場合、当校はすでに受領した金銭を速やかに返還し、損害賠償または違約金を請求しません。
  2. 前項の期間が経過した後も、保護者は、契約期間中いつでも将来に向かって契約を解除することができます。この場合に当校が請求できる額は、法令に定める上限（役務の提供開始前は11,000円、提供開始後はすでに提供した役務の対価に加えて、2万円または1か月分の受講料相当額のいずれか低い額）を超えないものとします。
  3. 本条の定めは、法令の定めが本規約の他の条項に優先して適用されることを確認するものです。本規約のいずれかの条項が法令に反する場合、その限りにおいて当該条項は適用されず、法令の定めによります。

第24条規約の変更

  1. 当校は、必要がある場合、本規約を変更することがあります。
  2. 本規約を変更する場合、変更後の内容および効力発生日を、効力発生日の少なくとも14日前までに、公式LINE、マイページまたは本ウェブサイトにて周知します。
  3. 周知の後、効力発生日以降に本サービスをご利用いただいた場合、変更後の本規約にご同意いただいたものとみなします。
  4. 変更の内容が保護者にとって重大な不利益となる場合は、個別にご案内し、ご同意をいただくよう努めます。

第25条準拠法・管轄

  1. 本規約は、日本法に準拠し、日本法に従って解釈されます。
  2. 本サービスに関して当校と保護者または会員との間に紛争が生じた場合、まず誠意をもって協議するものとします。
  3. 協議によって解決しない場合、熊本地方裁判所八代支部を第一審の合意管轄裁判所とします。
